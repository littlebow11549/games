# 🎮 Games

遊戲庫。純前端小遊戲合集，每款一個獨立資料夾，根目錄 `index.html` 為遊戲選單首頁。

| 編號 | 遊戲 | 資料夾 |
|------|------|--------|
| 01 | Memory Crash | `01_memory_crash/` |
| 02 | 勇氣超人 Brave Guy（3D 動作原型） | `02_xianxia_battle/` |

每款遊戲的美術/音樂素材規格清單放在 `NN_game/assets/ASSETS.md`，格式見根目錄範本 `ASSETS_TEMPLATE.md`。

## 交接與首頁維護

Claude 與其他協作者請先讀 [交接入口](docs/HANDOFF.md)。每次製作都需更新交接報告。
首頁使用 `index.html`、`assets/css/hub.css` 與 `assets/js/hub.js`，支援六種語言、遊戲類型與最愛。首頁來源素材存放 `assets/source/`。
