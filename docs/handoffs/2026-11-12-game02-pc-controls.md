# 勇氣超人：電腦操作改為滑鼠攻擊與鍵盤快捷鍵（2026-11-12，Claude）

## 使用者要求
- 電腦操作要改成滑鼠點擊就是普通攻擊，並設定技能的鍵盤快捷鍵。

## 完成內容（`02_xianxia_battle/`）

| 動作 | 電腦 | 備用鍵 |
|------|------|--------|
| 移動 | WASD 或方向鍵 | |
| 普通攻擊 | 滑鼠左鍵（可按住連打） | J |
| 閃避 | 滑鼠右鍵 | Shift |
| 小招 1 勇氣衝拳 | Q | K |
| 小招 2 氣功彈 | E | L |
| 小招 3 氣功震地 | R | I |
| 大招 超勇氣波 | F | O |
| 變身（可按住拖延） | 空白鍵 | |
| 對話下一句 | 滑鼠點對話框、空白鍵、Enter | Esc 跳過 |

- **朝游標方向打**：用滑鼠時，普攻、三個小招、大招起手都面向游標指到的地面位置；大招施放中光束會跟著游標轉。沒在用滑鼠（觸控或純鍵盤）時維持原本的行為：朝移動方向，沒移動就自動朝最近的敵人。
- `js/input.js`：新增滑鼠輸入與游標追蹤；按鍵表改為上表。只有點在遊戲畫面上才算攻擊，點 HUD 按鈕不會誤觸。
- `js/main.js`：以射線求游標在地面的落點（`mouseYaw()`）；開始畫面的操作說明依裝置顯示手機版或電腦版。
- `index.html`、`css/game.css`：電腦上（`pointer: fine`）每顆按鈕下方標出快捷鍵、隱藏虛擬搖桿、游標改成準星。手機不受影響。
- 快捷鍵的配置（Q／E／R／F）是 Claude 依常見動作遊戲的習慣選的，使用者只指定了「滑鼠攻擊」與「要有鍵盤快捷鍵」。

## 驗證（無頭 Chromium，1280×720）
- 左鍵點主角的右、左、上方：都進入攻擊狀態，面向分別為 89°、−89°、180°。
- 右鍵：觸發閃避。按住左鍵 1.5 秒：連段打到第三下。
- Q、E、R、K、L、I 各自放出對應的小招；F 與 O 放出大招。
- 大招中移動游標，光束方向跟著改變。
- 點暫停鍵：暫停，主角沒有誤出拳。
- **未驗證**：真人手感；觸控板的雙指點擊是否等同右鍵依系統設定而異；有滑鼠的平板等混合裝置。
