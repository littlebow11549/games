# brave音效包接入、揮空分層與自動最近鎖定

## 本輪授權與來源
- 使用者補傳brave_guy_sound.zip，要求從中找揮空與打擊音效，並修復黏住單一目標、方向切換與倒退出拳。
- 原ZIP與全部12個WAV（含temp長檔）完整歸檔於 `02_brave_guy/assets/source/sfx/imports/brave_guy/`。不再僅留暫存目錄。
- `USAGE.json`記錄輸出對照、來源SHA256、時長、峰值與削波樣本數。s04與先前使用者提供的hit.wav位元組相同。

## 音效配置
- s13 → swing_whoosh（0.182秒，峰值-10dBFS），所有普攻出手就播，揮空也有。
- s04/s08/s10 → hit_light/hit_snap/hit_sharp，普通命中輪替（0.289/0.221/0.285秒，峰值-4dBFS）。
- s05 → hit_heavy，重擊／暴擊（0.310秒，峰值-3dBFS）。
- 輸出於 `assets/source/sfx/brave/`；用adeclip、去首尾空白、44100Hz單聲道、峰值調整、3ms入／12ms出淡化，全部輸出0個削波樣本。以上是檔案量測與用途配置，不聲稱人工完整試聽辨識所有無語意來源。
- 移除crit強制轉hit的舊覆蓋，兩者仍共用100ms命中節流。揮拳與命中各自觸發；未命中／護盾／無敵不播普通命中音，格擋只用既有guard音。三種戰鬥音未解碼完成不回退合成雜訊。
- 保留其他Seal技能／UI音效與BGM；既有試聽清單同步目前manifest（補S86/S87死亡變化與S88登場），共38BGM、88SFX槽位。B/S既有編號不變。

## 鎖定及朝向
- 舊lockTarget只要原目標有效便直接回傳，是黏住原目標的原因；現在自由操作期間每次重新以距離排序找有效最近敵人。
- 切換鍵排除當前實際鎖定對象（不再只排除上次手選記錄）；搭配方向鍵使用既有90度方向扇區內最近敵人，沒候選不跳到反方向。
- 手動切換保留1.2秒，避免下一幀自動搜尋蓋掉手選。失效敵人不受保留保護。
- 出拳／衝拳／氣彈使用actionLockTarget記錄本次出手目標，不在單次攻擊中換成身後新近敵人；下一次出手fresh搜尋。目標失效時停止追蹤、保留這一拳方向，收招回自由狀態重搜。
- 自由移動時不強迫身體朝後方鎖定目標倒退跑；出手時仍朝鎖定目標。每次update同步模型root.rotation.y與hero.yaw。
