# 客串爆氣出現時操作區固定

- 基於本機前一項去字版 `c2bb0db`；只改客串爆氣顯示時的控制區參照，不更換素材或改玩法。
- 舊規則用 `.actions:has(.transform:not([hidden]))` 把 T 鎖定與 Y 切換的底部位置從 202px 改成 252px。小天使／惡夢用同一個按鈕元件，滿條時也跟著跳了 50px（矮視窗原有 0.8 縮放下，實際 40px）。
- 把讓位規則限制在非客串控制區，且以 `:where()` 保持原選擇器權重，原主角規則與基礎型態覆蓋不變。客串的兩顆鎖定鍵固定在原未滿條位置；寶石固定右 144px、底 224px、68×68。寶石與切換鍵的基本水平間隙 24px，矮視窗約 19.2px。不可用時仍由原 `hidden` 管理，不佔位、不攔截點擊。
- 爆氣出現、使用中、封印與重滿本身不搬動按鍵；終章劇情真的改變戰鬥型態時，其既有技能封印和基礎型態行為不改。HUD 其他定位、量表與音效規則皆未改。iframe 與樣式快取使用 `20261120stableburst`，去字版主模組和樣式保持版本。
