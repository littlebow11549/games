# 全數字樣式還原

## 需求與版本
使用者要求「數字都改回上一個版本」。以PR50之前的`13ab5369`數字樣式為基準；PR52已還原連擊，本次補齊剩餘數字覆寫。

## 完成內容
- 移除`css/comic-polish.css`對`.art-number`／`.dmg.crit`的金色多層描邊、陰影、字距與斜體覆寫，讓波次及暴擊數字使用原有CSS。
- 移除`.dmg.hurt`新版27px字級、描邊、色彩與陰影覆寫，恢復原受傷數字。
- 核對連擊、一般傷害、治療、血量、時間、結算及排行：保留既有舊版樣式及數值計算。此輪沒有新增美術或修改圖片；圖片過場、無損壓縮、操作按鈕、受擊震動及停頓保留。
- 更新外層入口與comic-polish.css版本鍵為`20261116numbers`，避免舊CSS快取。

## 驗證與發布
已由390px手機直式入口檢查8組數字元素的字級、字型、色彩、描邊、陰影與字距，確認不再受comic-polish新版數字覆寫影響；傷害樣本包含實際使用的system-lettering類別。受傷數字恢復19px及原粉紅色，無頁面錯誤。另核對歷史差異，時間、結算及排行未新增數字覆寫。既有正式入口測試的版本鍵同步更新。本次PR合併後由GitHub Pages發布，正式部署與線上核對結果於交付訊息回報。
