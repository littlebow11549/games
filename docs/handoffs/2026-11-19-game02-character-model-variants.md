# 一般尺寸小天使與兩款小精靈

新增三款獨立程式模型（非新 GLB）：`angel_playable`、`student_spirit`、`brave_spirit`，定義在 `02_brave_guy/js/visuals.js`。沿用既有角色幾何骨架、色彩與動畫，不重製設定圖片。

- 小天使可操作模型使用一般人形比例，有完整手腳、紅白上衣、藍裙、粉紅長髮、雙角鈴帽、白色羽翼；支援移動、受擊、閃避及施法舉手。原跟隨用 angel 保留。
- 主角小精靈保留黃衣／帽與深色褲，勇氣超人小精靈保留刺髮、紅圍巾／手套及綠護膝。兩者獨立模型 ID，0.42 骨架比例、1.35 倍頭部、羽翼拍動與浮動。
- main.js：小天使玩家配主角小精靈；惡夢玩家配勇氣超人小精靈。小精靈模型自身處理尺寸，移除原外層0.35再次縮小。進關、關中及終章重置保持模型。原主角救援仍用原小天使。
- play.html/main.js 更新快取版本。game02-playable-roster.cjs 更新新模型 ID 的驗證。

驗證：三模型同一攝影機實際渲染，比例／配色／翅膀目視確認；既有選角、八招、救援、換關及終章回歸。截圖只放 /tmp，不新增驗收頁。仍為遊戲既有風格的簡化幾何模型，非精細骨架美術交付。
