# 選關、暫停、結算美術接入與庫存盤點

## 使用者要求
先盤點所有既有素材與 Claude 需求，避免重做；優先完成選關、暫停、每關結算，按鈕必須等寬。使用者提供手機暫停與3-2結算截圖，顯示標題描邊破碎、按鈕尺寸不一。

## 實際完成

- `css/overlay-art.css`：暫停與結算共用插畫框／標題牌／六態按鈕圖集，原圖未修改；中央以純色CSS填底，不使用來源圖半透明中心。取消標題文字描邊，保留中英文即時文字。主要操作與語系按鈕等寬；短橫向螢幕可捲動。
- 選關沿用既有 `brave_guy_ui17_介面面板圖集.png`，14關卡片依同一 grid 欄寬排列，修正 auto-fit 導致少關卡章節撐寬的問題。原開放、鎖定、已過關、目前關卡狀態保留。
- `js/main.js`：結算分開顯示關卡名、秒數、擊倒數；過關、失敗、終章有不同背景狀態；保留重打、下一關、降難度、選關與回遊戲中心。補上結算畫面切語系後重新渲染標題／成績／說明。
- 主標題漫畫格引用本輪兩張 keyart，橫直向分圖；選關沿用既有背景與圖集，不使用本輪新增場景圖。
- `index.html` 載入新樣式。
