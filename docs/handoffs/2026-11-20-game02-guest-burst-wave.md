# 客串爆氣共用變身衝擊波

- 基準：Pages 順序已先上副本出生置中（線上提交 `b40c3c5`，等同本機 `af45d93`）。本次只變更爆氣特效。
- 小天使與惡夢滿條後以寶石／鍵盤成功手動爆氣，使用一般變身釋放的同一組 `shockwaveVisual`：半球光罩向外擴張（0.55 秒）、白色地面衝擊環（0.45 秒）、36 顆爆散粒子（約 0.5 秒），以及原變身適度震動。減少動態設定依既有規則關閉鏡頭震動。
- 特效以當前角色位置為圓心，使用一般變身的基準半徑 6。小天使保留粉色，惡夢保留紫色，光環與既有爆氣音效留用。未滿條、已爆氣、終章封印或僅滿條未操作都不播放。
- 視覺從碰撞傷害函式拆出，客串不會因爆炸追加傷害、擊退、浮空、暈眩或停格。維持原 8 秒、傷害 ×1.5、移速 ×1.15、受傷 ×0.8、起動 0.6 秒無敵。主角一般／蓄力變身與自動罪惡感爆發已共用該組效果，保留各自範圍、外觀、音效與傷害，主角「悶爆」也原樣保留。
- `index.html` 內嵌入口與 `play.html` 主模組快取更新為 `20261120burstwave`。未改動或新增任何素材。
