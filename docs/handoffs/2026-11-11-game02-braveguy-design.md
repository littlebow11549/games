# 第二款遊戲改為《勇氣超人 Brave Guy》：概念圖歸檔與企劃書（2026-11-11，Claude）

## 使用者要求（依對話順序）
1. 要做的遊戲是《勇氣超人》，使用者大學時期的原創作品；提供封面與封底兩張概念圖。
2. 主角是一般大學生，夢裡進入內心的黑暗迷宮；小天使賜予力量，讓他變身勇氣超人。
3. 封面中間上方後面那位是惡夢超人：勇氣超人的反面、主角內心的黑影。依這套美術設定重做企劃。
4. 舞台是主角內心的黑暗世界，有校園、有野外；重點是主角自己尋求內心突破；角色與設定互相呼應。
5. 作者已出社會，故事觀要擴充，加入職場；整個故事架構再擴充。
6. 做三大地圖關卡，呼應不同年紀。先做出基本的設計底，再擴充美術。
7. 小天使外表美麗但毒舌。對話要充滿喜劇、賤賤的有趣橋段。
8. 構築遊戲劇情腳本。
