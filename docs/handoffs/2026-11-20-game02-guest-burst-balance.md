# 客串爆氣、天下無敵防禦與惡夢砲彈清晰度

## 使用者確認
兩位客串隱藏勇氣條，但保留罪惡感原位置的專屬量表：小天使「包容心」、惡夢「極限值」。集滿後由玩家按寶石爆氣，不自動觸發。

## 完成規則
- 專屬量表容量100。保留受傷及敵人情勒累積，另每次有效命中+1.5、擊殺+2，最多100。滿條不自動爆氣；原 guiltBurst 對客串只限制上限。爆氣期間不靠命中／受傷／情勒充能。
- 寶石按鈕滿條顯示，按下或空白鍵啟動8秒爆氣，耗盡量表：傷害×1.25、移速×1.15、受到傷害×0.8，起動0.6秒無敵，角色輪廓發光／光環。量表顯示爆氣倒數，期間不再顯示按鈕；結束保留客串形態，無凡人轉換。換關重設，終章腳本封印時清除。
- 包容心／極限值／爆氣標籤與按鈕提示支援中英日。主角原罪惡感及變身邏輯保留。
- 天下無敵（rounds>3）所有敵人承傷÷3，在既有護盾、鎧甲及Boss階段保護前套用；一般進度不套用。
- 天下無敵勇氣超人與客串在非終章腳本封印期間固定100勇氣、使用持續形態，不會因扣勇氣／舊burst計時歸零而退回凡人。涵蓋藍教頭關卡；終章原「沒有超能力」腳本仍生效。沒有改成生命無敵，原致死／救援規則保留。
- 惡夢玩家F直接2.4→1.8、濺射1.2→0.9、最後全場6→4.5（均-25%）；仍十門、獨立飛行、8.4秒召回、10秒全圖轟炸，範圍／擊退／時長不變。Boss版傷害不隨本次削弱。
