# 勇氣超人：載入與效能改善（2026-11-12，Claude）

## 使用者回報
- 開不起來，讀取很久；嘗試提升效能。

## 沒有使用者裝置的資訊
使用者沒有說明裝置、瀏覽器與卡在哪個畫面，Claude 也無法在實體手機上重現。以下是依程式找出的三個可能原因，全部處理；**哪一個才是使用者實際遇到的，尚未確認**。

## 處理的問題

### 1. 舊頁面配新程式會永遠卡在「載入中」
GitHub Pages 的檔案快取 10 分鐘，瀏覽器也會快取。上一次更新（14 關）在 `index.html` 新增了對話框與選關的元素；如果瀏覽器拿到舊的 `index.html` 卻載到新的 `js/main.js`，程式在找不到元素時就整個停住，畫面沒有任何提示。
- `js/main.js` 啟動時檢查必要元素，缺少就帶時間參數重新抓一次頁面。
- `index.html` 的 CSS 與主程式網址加上版本參數。

### 2. 載入失敗沒有任何提示
- `index.html` 新增一小段不依賴模組的程式：出錯時把訊息顯示在開始畫面並附「重新載入」；9 秒還沒開好也會提示。

### 3. 較舊的手機瀏覽器不支援 import map
原本用 import map 解析 `three`（iOS 16.4 之前的 Safari 不支援，整個遊戲不會啟動）。
- 全部改成相對路徑匯入，移除 import map（含 `vendor/three/addons/` 三個檔的匯入行，已在行尾註明）。

### 4. 載入量
- GLB 載入器（約 150KB）改成 manifest 真的指定模型時才動態載入。
- 加上 `modulepreload`，各模組平行下載。
- 請求數 19 → 16。

### 5. 執行效能
- **畫質分級**（低／中／高）：手機預設「中」（像素比上限 1.5、陰影貼圖 1024、關抗鋸齒），電腦「高」。
- **自動降級**：遊玩中連續約 6 秒平均低於 38 FPS 就降一級，並記在 `localStorage`（`braveguy.quality`），下次直接用較低等級。只降不升。網址加 `?q=0／1／2` 可強制指定。
- 低畫質：關即時陰影、像素比 1、同場小怪數量 ×0.7。
- **小怪不再投射即時陰影**，改用腳下一片共用的假陰影；場景擺設也不投射。陰影那一輪的繪製次數大幅減少。
- HUD 每幀的按鈕查詢改成啟動時查一次。

## 後續：確認了卡住的原因，並加上讀取進度條（同日）

### 使用者回報
- 截圖顯示開始畫面出現「載入失敗：Uncaught Error: Error creating WebGL context.」（電腦瀏覽器）。
- 要求：給一個讀取中的進度條，讓人知道進度。

### 原因
**使用者的瀏覽器無法建立 WebGL（3D 繪圖）環境。** 這與網路、載入量、效能都無關；上面第 1–5 項的修正沒有對到真正的原因（但第 2 項加的錯誤提示讓原因現形了）。為什麼那個瀏覽器不能用 WebGL，Claude 無法從這裡得知，常見情況是硬體加速被關閉、在內嵌或遠端的瀏覽器裡開啟、或同時開了太多 3D 分頁。

### 完成內容
- **WebGL 啟動失敗的處理**（`js/main.js`）：依序用三種越來越保守的設定嘗試建立；全部失敗時偵測瀏覽器支援 WebGL 2／WebGL 1／都不支援，在開始畫面顯示對應的原因與解法（開啟硬體加速、改用一般瀏覽器、改用手機），並附上瀏覽器自己回報的原因。
- **讀取進度條**（`index.html`、`css/game.css`、`js/main.js`）：
  - 3%–55%：3D 引擎（佔程式九成），以串流下載、依實際位元組數推進。下載完才載入主程式。
  - 55%–60%：其餘程式檔，每完成一個前進一格。
  - 60%–100%：啟動 3D 繪圖、建立場景、讀取設定、載入角色模型（有的話逐個顯示）、準備選關畫面。
  - 進度只會往前；完成後自動隱藏；超過 12 秒會加註提示。
- 進關後音樂下載時，任務欄顯示「♪ 音樂載入中…」。

### 驗證
- 模擬慢速網路：進度條從 3% 平滑推進（3D 引擎階段約 160 次更新），各階段文字依序出現，完成後隱藏，選單正常。
- 以關閉 WebGL 的瀏覽器開啟：顯示「3D 繪圖啟動失敗」、原因、解法與瀏覽器回報的訊息，進度條隱藏，開始鍵維持不可按。
- 觸控流程、舊頁面自動重新載入、14 關逐關腳本：通過。

### 尚未解決
- **沒有 WebGL 的瀏覽器還是玩不了**，現在只是清楚說明原因。這款遊戲用的 3D 引擎版本需要 WebGL 2，沒有非 3D 的後備畫面。
- 使用者那台電腦為何無法建立 WebGL 環境，仍待使用者依畫面上的解法嘗試後回報。
- 3D 引擎會被請求兩次（進度條的串流下載一次、模組匯入一次），第二次預期由瀏覽器快取提供；上線後另行確認。
