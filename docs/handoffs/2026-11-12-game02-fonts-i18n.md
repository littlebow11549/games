# 2026-11-12 勇氣超人：新字型與中英語系切換（Claude）

## 使用者要求

「要有語系切換，目前的中文字型很難看。雖然不是正式的但也請做漂亮一點。」

## 完成內容

### 字型

- 內文、對話、泡泡改用 **jf open 粉圓**（圓潤、喜劇感）；標題、橫幅、按鍵、傷害數字改用 **思源黑體 Black**。兩者皆為 SIL OFL 1.1，可商用、可內嵌。
- 只內嵌遊戲用到的約 1,450 字：`02_xianxia_battle/assets/fonts/huninn-subset.woff2`（277 KB）、`notosanstc-black-subset.woff2`（231 KB）。`index.html` 有 preload，`font-display: swap`。
- 產生工具 `tools/make_game02_fonts.py`（需 `pip install fonttools brotli`）。**改了遊戲文字要重跑**，否則新字退回系統字型。

### 語系切換

- 目前兩種：**繁體中文（預設）**、**English**。標題畫面與暫停選單各有一顆「🌐」按鈕，切換後立刻生效並記在 localStorage `braveguy.lang`；網址 `?lang=en`／`?lang=zh-Hant` 可強制。
- 做法：中文原文當鍵。`js/i18n.js` 提供 `t('中文')`、`tf('第 {0} 波', n)`、`applyStatic()`；英文字典在 `js/lang_en.js`（598 條）。找不到翻譯會顯示中文原文，不會壞。
- 已翻譯：全部劇情對話、關卡與地圖名稱、角色名、小天使吐槽、怪的嘲諷、守關者台詞、戰鬥跳字、HUD、選單、結算、暫停選單、按鍵標示。
- 諧音名的英文版（Claude 自訂，待使用者確認）：小幹譙 Lil' Cuss、幹譙龍 Cussaur、悶幹譙 Bottled Cuss、佛賴弟 Snoozy Freddie、假森 Jay-Sham、假忙森 Busy-Sham、俊熊 Toshi-Bear、錢大姐 Big Sis Robyn（robbin'）、藍教頭 Sgt. Dick Blue、冠老闆 Boss Royal Payne（royal pain）、新雞 Skeemy Chick、八卦蛇 Gossip Snake、加班鬼 Overtime Ghoul、玫良鑫 Noh Konshens Co., Ltd.、惡夢／地獄／夢魘超人 Nightmare／Hell／Incubus Guy。
- 要加新語言：在 `js/` 加一個 `lang_xx.js`，在 `i18n.js` 的 `DICTS` 與 `LANGS` 各加一行。

## 測試結果

無頭瀏覽器：兩個字型皆載入；切換英文後跑完 14 關的全部對話與 HUD，**沒有殘留中文**；重新整理後語系保留；14 關腳本通關、觸控、鍵盤、暫停、音樂切換回歸皆無錯誤。

**未涵蓋**：讀取進度條最前段（主程式載入前）與 WebGL 啟動失敗的說明仍只有中文；英文翻譯未經母語者校對；首頁（遊戲中心）有六種語系，遊戲內目前只有兩種。
