# 天下無敵三角色：實作交付

## 入口與玩法
- 天下無敵門檻沿用save.rounds>3；每次正常進關／重打／下一關先顯示角色選擇。未解鎖不顯示，傳入替代角色ID也會回到原主角。
- 原生dialog：勇氣超人、小天使、惡夢超人三卡，沿用現有頭像／設定集特寫；手機直排、桌面三欄、短視窗可捲動，支援返回與Escape。取消不啟動新關卡／不重置計時。
- hero.character獨立於hero.form，原技能／勇氣計量沿用；模型映射復用既有createVisual('angel'/'nightmare')。終章失去能力仍保留選擇角色外觀，照原流程走向Boss。
- 原勇氣超人四招不變；替代角色保存通關進度、保留難度與救援規則，但不列入原一般計時排行。結算明示換角不列榜。

- 效果只以模擬dt推進，暫停不繼續攻擊；進階段電影清除客串技能，避免電影後殘留爆炸。

## 救援與對話
- 小天使玩家 → 主角救援；惡夢超人玩家 → 勇氣超人救援。兩者救援模型沿用勇氣超人縮至0.35、漂浮跟隨的小精靈型態。
- 原主角／勇氣超人玩家維持小天使救援。
- 救援沿用45%回血、2.5秒無敵與既有額度；保留輕鬆5／普通4／地獄3上限、每50連擊補一次。不因替代角色先退回學生而失去角色身份。
- HUD標籤、氣泡說話者與救援光圈同步切換。綠金救援效果，救援者短暫靠近玩家；不重繪圖片。
- 已接進場、Boss遭遇、關中提示、受傷（5秒節流）、回嘴、勝利、過關後雙人對話；同角色Boss相遇有專句。
- 救援台詞：首次／再次／剩一次／耗盡／連擊補回，兩組專屬對白，救援者先說、玩家2.5秒後回應。首次救援優先顯示首次台詞。
- 故事主線仍視為夢境重演，原Boss電影與結局美術沿用，不宣稱已製作兩套新過場動畫。
