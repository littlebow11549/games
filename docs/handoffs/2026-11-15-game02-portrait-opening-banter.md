### 畫面入口
- index.html 為固定 9:16 的同來源 iframe 外框；原本遊戲文件移至 play.html。CSS 動態視窗單位適配網址列及安全區，不拉伸遊戲畫面。查詢參數（含語系／素材測試）與 hash 傳入。

### 七幕開場（HTML/CSS 動態故事）
1. 日常吞下嘲笑與責怪，習慣說沒關係。
2. 期中考前夜，在宿舍課本上睡著。
3. 醒來房門後出現扭曲校園。
4. 踏入自己的內心，壓抑的恐懼有了形狀。
5. 小天使說明這裡是內心，力量能給、路要自己走。
6. 惡言化為心魔，離開前必須面對。
7. 主角承認害怕，但決定自己往前走。

三語標題／敘述／控制；首次載入自動開啟，按開始故事解鎖音訊後每幕6秒、共約42秒，也可手動下一幕／跳過；完成或跳過保存 seenOpening，之後不自動重播，選單提供重播。背景分頁不推進，減少動態設定停止裝飾動畫。開場期間不渲染戰鬥畫面、不更新敵人；離開時清除輸入佇列。

開場只復用 ui/portrait_student.png、sheet/unified/sheet_angel.png 與 sheet_ganqiao.png，CSS 在執行時取景，不改原圖。宿舍窗、書桌、異常門、光環是 CSS 圖形；未使用待追溯 scene_* 草稿、未重新生成場景。屬 H5 動態故事卡與圖像演出，不宣稱新增完整逐格動畫。

### Boss 以對嗆為主
- boss-banter.js：13 位 Boss，每位「Boss挑釁→主角回嗆→Boss接話」三句，中英日共117句。
- 所有 Boss 統一三鏡 4＋4＋4 秒（共12秒，切點4／8），雙魔王依序24秒。原分鏡圖不變，原音效節點按新切點重排。
- 爆裂多角對話框＋藝術字說話者，Boss暖白框、主角淡綠框。每次換句用0.38秒彈入與畫面震動，配合清脆／重擊音效；讀取後保持穩定。
- 所有 Boss 都有震動，非僅部分 motif；系統 prefers-reduced-motion 時停用震動，台詞與音效保留。過場取消清除震動狀態。
