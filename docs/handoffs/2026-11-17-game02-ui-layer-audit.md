# UI 堆疊順序檢驗與統一

## 問題與調整
- Boss 血條原本高於未指定層級的「心魔來襲」提示。
- 連擊原有 z-index 1100，高於載入畫面；碎片特效亦可能高於對話／暫停。
- 新增最後載入的 css/ui-layers.css，集中管理全域與 HUD 內部層級，保留既有美術與玩法。
- 全域低至高：場景 0、受擊效果 5、HUD 10、碎片 20、連擊 30、對話 40、選單／結算 50、暫停 60、過場 70、開場 80、載入 100。原生清除進度確認視窗維持瀏覽器 top layer。
- HUD 內低至高：世界標示／小怪血條 0、小天使氣泡 1、任務 2、主角數值／異常狀態 3、小地圖 4、Boss 血條 5、操作區 6、事件提示 7。
- 裝飾層不攔截點擊。對話、選單、暫停、影片、載入或 HUD 隱藏時，隱藏戰鬥連擊／碎片／受擊效果。
- 字藝寬度增加 90svh 上限，避免短橫式畫面過度遮擋。
