## 語言與狀態

- localStorage `gamehub_language`：zh-Hant / zh-Hans / en / ja / ko / th。
- localStorage `gamehub_favorites`：穩定遊戲 ID 陣列，例如 ["memory-crash"]，不要以翻譯名稱當主鍵。
- 首次依 navigator.languages 判定；zh-CN/zh-SG/zh-Hans 為簡中，其他 zh 為繁中；支援 ja/ko/th/en，無匹配回退繁中。
- 儲存資料格式損毀時安全回退；瀏覽器禁止儲存時，本次頁面仍可使用切換與收藏，並顯示提示。
- 語言切換不重載頁面，保留當前分類及收藏；更新 html lang 與所有帶 data-i18n 的內容。
- 這次語系功能僅屬首頁，Memory Crash 遊戲內語言尚未改動。翻譯需母語者後續潤飾時，修改 COPY 即可。

## 後續新增遊戲

1. 在 assets/js/hub.js 的 GAMES 加入唯一 id、folder、name、descriptionKey、icon、categories 與 status: ready。
2. descriptionKey 必須在六個 COPY 字典都提供翻譯；新增類型時也同步字典與 index.html 篩選按鈕。
3. 分類 ID：puzzle / memory / action / casual；一款可屬多類。
4. 本期精選 Banner 仍固定連往 Memory Crash；若換精選，需同步 Banner 文案、圖、連結與編號。
5. 空位僅為排版占位，不表示已開發的遊戲。原遊戲內頁保持獨立，不要把首頁語言功能與遊戲邏輯耦合。
