# 角色戰鬥強化：PUA砲陣、小天使狀態與過關流程

## 最終行為
- 大招「王之嘴炮」在角色背後展開十道紫金傳送門，依角色位置與面向跟隨，分批射出PUA對話砲；不是整群一起移動，也不是環繞身旁的十顆球。
- 每發獨立選擇目標、飛行、命中及消失。玩家版飛行中目標失效會重新選最近有效敵人，目標分配輪替以覆蓋敵群。射速38單位/秒，約每門0.5秒一發，第8.4秒停止射擊，十個文字子機召回身邊聚能；第10秒全場轟炸後清除。
- 一般E技能改為5台／5秒本體飛出去追敵，射出的彈也改為PUA對話。三款超人Boss同款E/F同步採用文字攻擊。
- 玩家大招清場強化：直接命中2.4倍傷害／擊退9／浮空4，周遭3.6範圍其他敵人1.2倍／擊退7／浮空3；結束時全場有效目標6倍／擊退18／浮空8，紫綠擴散波。結尾粒子最多24處，避免大量敵人同時開粒子。
- Boss版保留較慢速度20、每門0.75秒及直線射擊；每發發射前0.28秒地面提示，命中65基礎傷害，保留原難度及主角受擊無敵。Boss沒有玩家版必中全場傷害；末段另有10個分散落點，提前0.9秒地面預警，爆炸基礎傷害130，每次結尾最多命中一次，可離開標記躲避。原Boss大招起手1.15秒仍保留。
- 一般／大招對話範例：都是為你好、你想太多了、你讓我很失望、都是你的錯、別人都可以、我沒關係。全部有英日對應；實際傷害仍走既有盾、無敵、計分與救援邏輯。
- 大招喊話與藝術字：中文王之嘴炮，英文Royal Barrage!，日文王の口撃！。小天使大招語系維持前次接入。


## 小天使與過關流程
- 第一招射程17→28、寬度4→8、傷害倍率3.4→4.8、擊退22、浮空9；文字彈視覺1.6倍。氣流使用較低透明度，清楚展示寬度而不蓋白地面。fx.trail新增可選透明度參數，其他招式預設不變。
- 凍結3秒／麻痺1.8秒，Boss最多0.4秒、2.5秒控制抗性不變。新增敵人頭上中英日狀態標記與0.1秒倒數、凍結藍色／麻痺黃色模型光；吹飛與聚攏另有標記，Boss免控時間顯示「控制抗性」。同時控制保留較長時間的狀態名稱。標記避開Boss血條，死亡、離開畫面與換關會清理。
- 小天使／惡夢過關不播原主角的Boss勝利動畫，也不插入過關後對話；直接結算，下一關進選角。最終跳過原主角結局影片，直接5秒Staff，仍沿用輪數與解鎖通知。原主角流程、Boss出場、敗北與戰鬥內階段過場不變。
- cinematics.ending新增creditsOnly參數；main.js按角色選擇。未解鎖角色與進度防重複計數規則保留。
