# game_center 素材索引

原始圖像、音訊與影片內容未修改。角色採用使用者指定的 `charactor` 拼法；同角色共用編號，視角、表情、版本以用途後綴區別。

## 分類位置

- `source/pic/sheet/`：角色設定集；`unified/` 為遊戲現役裁切圖集。
- `source/pic/expressions/`：獨立表情特輯（勇氣超人）。
- `source/pic/icons/`、`ui/`、`titles/`：技能按鈕、介面與藝術文字。
- `runtime/`：程式實際載入的交付檔。
- `_alternate/`：尚未使用的備選素材。
- `records/`：交付、提示詞、檢查、來源和新舊檔名對照。

使用狀態：{'現役載入': 2, '正式母檔／設計參考': 1, '未使用備選': 0}。正式母檔／設計參考不等於已載入遊戲；不以收錄在索引內當作使用證據。
