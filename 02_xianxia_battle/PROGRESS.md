# 02 青玉劍試煉（暫定名）— 進度

狀態：**可玩原型＋簡單版美術**（2026-11-11）。角色與場景是程式拼的 3D 佔位物，UI／圖示／背景／Logo 是程式畫的簡單版 SVG；尚無任何正式美術、模型或音樂。
名稱「青玉劍試煉」為暫定；資料夾 `02_xianxia_battle` 是工作代號。**已加入首頁遊戲收藏（分類：動作）**。

## 已有功能
- Three.js r170（放在 `vendor/three/`，不需建置工具），斜俯視跟隨鏡頭、陰影、霧。
- 操作：虛擬搖桿＋鍵盤（WASD 移動、J 攻擊、K／L／I 技能、Shift 閃避）。沒推搖桿時攻擊會自動朝向最近的怪。
- 戰鬥：三連段普攻、旋風斬、劍氣、天降巨劍、閃避無敵；暴擊、擊退、命中頓幀、鏡頭震動、傷害跳字。
- 怪物：持槍兵（近戰）、小精怪（快速）、植物怪（遠程），三波後出 Boss（範圍重擊有預警圈、衝撞、半血召喚）。
- 3D 特效：刀光、衝擊環、粒子爆散、光柱、巨劍落下，全是場景內網格與粒子。
- HUD：血條／靈力條、技能冷卻、任務面板、Boss 血條、怪物血條、暫停、靜音、勝敗結算與重來。
- 素材插槽：`assets/manifest.json`，接入方式見 `assets/README.md`。

## 檔案
| 檔案 | 內容 |
|------|------|
| `index.html`、`css/game.css` | 頁面與佔位 UI |
| `js/main.js` | 迴圈、主角、怪物 AI、判定、波次、HUD；數值表在檔案開頭 |
| `js/visuals.js` | 角色外觀：佔位角色（程式動畫）與 GLB 角色（骨架動畫） |
| `js/world.js` | 程式生成的森林空地 |
| `js/fx.js` | 3D 特效 |
| `js/input.js`、`js/audio.js` | 輸入、音訊（合成音效＋BGM 插槽） |
| `assets/source/pic/` | 簡單版美術（65 張 SVG＋17 張三視圖 PNG）；UI 由 `css/game.css` 末段直接引用 |
| `tools/make_simple_art.py` | 產生簡單版 SVG |
| `tools/concept.html`、`tools/render_concepts.cjs` | 把佔位角色輸出成三視圖 |
