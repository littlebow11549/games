# 勇氣超人 Brave Guy — 角色設定集與「角色設定合輯」需求（v0.4）

使用者要求：**每一個角色都要做角色設定合輯**，版式參考使用者提供的範例圖
[`assets/source/pic/reference/sheet_layout_example.webp`](assets/source/pic/reference/sheet_layout_example.webp)。
那張範例是別的角色，**只參考版式，不沿用它的角色、Logo、配色**。

本檔由 `tools/make_character_bible.py` 產生。造型以兩張概念圖為準（`assets/source/pic/reference/`）；
標「新設計」的角色概念圖裡沒有，造型是 Claude 的文字提案。色碼是 Claude 看概念圖估的近似值，出圖時以概念圖實際顏色為準。

**Claude 沒有繪圖能力，合輯圖本身要由繪圖 AI（GPT）或使用者製作。** 本檔提供的是：統一版式、每個角色要填的內容、可直接貼的提示詞。

---

## 1. 合輯統一版式

一個角色一張，橫式，建議 **3072×2048**（至少 1536×1024），PNG。

| 區塊 | 位置 | 內容 |
|------|------|------|
| 標題列 | 最上方 | 左：BRAVE GUY 標誌（綠色能量球＋橘紅金立體字）。中：`CHARACTER TURNAROUND SHEET`。右：角色中文名與英文名 |
| 角色檔案 | 左欄上 | 名稱、定位、比例、個性、代表台詞、用途 |
| 配色 | 左欄下 | 5 個色塊各附色碼 |
| 轉面圖 | 右側第一列（最大） | **5 個角度：正面、前 3/4、側面、背面、後 3/4**。同一個自然站姿、同比例、腳底對齊同一條線 |
| 表情 | 右側第二列 | 6 個半身表情，各附標籤 |
| 細節特寫 | 右下偏左 | 6 格特寫，各附標籤 |
| 身高比例 | 右下 | 刻度尺；本角色與「主角・大學生（170 公分）」及一個成人剪影並排 |

**全系列共同規定**
- 畫風：逗趣可愛的日系卡通、粗黑描邊、高彩度平塗加簡單陰影，與概念圖一致。
- 比例：**保留概念圖原本的比例**（人形角色約 4–5 頭身），不改成 Q 版（使用者確認）。遊戲內的 3D 模型也照這個比例做。
- 合輯底色：深色（建議深綠黑 `#0E1A14`），框線用勇氣綠 `#3FB53A`，標題字用黃 `#F6C21C`。每張版面位置一致，16 張排在一起要像同一套。
- 版面上的說明文字用英文標籤（FRONT、SIDE、EXPRESSIONS…）即可，中文名放標題列。繪圖 AI 的中文字容易出錯，中文說明以本檔為準。

## 2. 合輯不等於 3D 生成用圖

合輯是給人看的總覽。要送進 Tripo 生 3D 的圖規格不同（見 `assets/ASSETS.md` §1）：

| | 角色設定合輯 | 3D 生成用圖 |
|--|--------------|-------------|
| 一張圖裡 | 多個角度＋表情＋特寫 | **只有一個角度** |
| 姿勢 | 自然站姿 | A 字站姿，手上不拿東西 |
| 背景 | 深色版面 | 純灰或純白，無陰影 |
| 尺寸 | 3072×2048 | 2048×2048 |

**建議流程**：先出合輯定案造型 → 使用者把關 → 再用同一角色另出正面、側面、背面三張 A 字站姿單圖給 Tripo。若合輯解析度夠高，轉面圖也可裁出來試生，但 A 字站姿的成功率比較高。

## 3. 製作順序

| 優先 | 角色 | 理由 |
|------|------|------|
| P0 | 主角・大學生、勇氣超人 | 設計底完成後第一批要換掉佔位模型的角色 |
| P1 | 小天使、惡夢超人、幹譙龍（三型態） | 序章與地圖一的核心 |
| P2 | 錢大姐、藍教頭、假森、佛賴弟、俊熊、地獄超人 | 地圖一、二其餘角色 |
| P3 | 主角・上班族、夢魘超人、冠老闆、新雞、八卦蛇 | 地圖三，且需新設計 |

地圖三是「玫良鑫有限公司」：冠老闆、新雞、八卦蛇是使用者指定的三隻職場怪物，需要新設計；其餘敵人是校園角色換上班的衣服，「職場版」列在各自合輯的變體欄，不另開新角色。

## 4. 通用提示詞

把下面整段貼給繪圖 AI，附上兩張概念圖與版式範例圖，再把 `{...}` 換成各角色小節的內容。

```
Create a CHARACTER TURNAROUND SHEET for a game character, landscape 3:2.
Follow the LAYOUT of the attached layout example (header bar; left column with character
profile and 5-swatch color palette; top row with 5 turnaround views labeled FRONT, 3/4 VIEW,
SIDE, BACK, 3/4 REAR; middle row with 6 labeled bust expressions; bottom-left 6 labeled
detail close-ups; bottom-right height scale chart). Use only the layout from that example,
not its character, logo or colors.
Character design must match the attached Brave Guy concept art: {角色在概念圖中的位置與外觀}.
Art style: cute and funny Japanese cartoon, thick black outlines, flat vivid colors with
simple cel shading. Keep the same body proportion as the concept art (about 4 to 5 heads
tall for humanoids, not chibi), keeping face and costume features. All 5 turnaround views: same neutral standing pose, same scale, feet on
one baseline, consistent costume details from every angle.
Sheet background dark green-black #0E1A14, frame lines green #3FB53A, heading text yellow
#F6C21C. Header: "BRAVE GUY" logo at left, "CHARACTER TURNAROUND SHEET" in the middle,
"{英文名}" at right.
Palette swatches: {色碼五個}.
Expressions (6): {表情六個}.
Detail close-ups (6): {細節六個}.
Scale chart: this character at {身高} cm next to a 170 cm student silhouette.
English labels only. No watermark.
```
