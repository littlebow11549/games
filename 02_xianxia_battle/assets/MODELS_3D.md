# 🧊 勇氣超人 Brave Guy — 3D 外包製作需求（v1.0，2026-11-13）

這份文件給**外包的 3D 製作者**看，可以單獨讀懂。2D 美術需求在 [`ASSETS.md`](ASSETS.md)，角色設定在 [`../CHARACTERS.md`](../CHARACTERS.md)，企劃在 [`../DESIGN.md`](../DESIGN.md)。

## 0. 先知道這幾件事

| 項目 | 內容 |
|------|------|
| 遊戲 | 俯視角 3D 無雙動作，網頁版（Three.js r170），手機橫式為主，一場同時最多約 120 隻怪 |
| 線上版 | <https://littlebow11549.github.io/games/02_xianxia_battle/>（目前全是程式拼的積木人，就是要被換掉的東西） |
| 造型依據 | 使用者的概念圖 `source/pic/reference/`，以及定案後的角色設定合輯 `source/pic/sheet/sheet_{id}.png`。**合輯沒定案的角色先不要開工** |
| 畫風 | 日系卡通、粗黑描邊感、高彩度平塗。保留原比例（人形約 4–5 頭身），不要 Q 版 |
| 鏡頭 | 固定斜俯視，角色在畫面上只有 60–200 像素高。**輪廓與配色比細節重要**，臉部表情幾乎看不到 |
| 兩條路線 | 路線 A：Claude 用圖轉 3D（Tripo）自動生成，品質夠用就用。**路線 B：外包手工製作**，就是這份文件。主角與黑影三型態建議一定走 B，小怪可先走 A |

## 1. 技術規格（每個模型都要符合）

| 項目 | 規定 |
|------|------|
| 檔案格式 | **glTF 2.0 二進位 `.glb`**，一個角色一個檔，模型、骨架、動作、貼圖全部打包在裡面 |
| 座標 | Y 軸朝上，角色面向 **+Z**，腳底在原點（Y=0），站在世界中心 |
| 單位 | 公尺。身高照 §3 表格；程式會再依表格身高自動縮放，所以比例正確比絕對值重要 |
| 面數（三角面） | 主角、黑影、守關者 **≤ 15,000**；小怪 **≤ 3,000**（同場上百隻）；道具 ≤ 1,500 |
| 材質 | 每個角色 **1 個材質、1 張貼圖**（小怪必須；主角與守關者最多 2 個）。glTF 標準 PBR 的 baseColor 即可，金屬度 0、粗糙度 1；程式會換成卡通著色。不要用透明混合（要鏤空用 alpha test） |
| 貼圖 | baseColor 一張，主角與守關者 1024×1024、小怪 512×512，PNG 內嵌。**不需要**法線、AO、金屬粗糙貼圖。可另附自發光貼圖（眼睛、能量） |
| 骨架 | 人形用標準 humanoid 骨架（Mixamo 命名相容最好），**≤ 40 根骨頭**；小怪 ≤ 25 根。每個頂點最多受 4 根骨頭影響。手部骨頭命名 `RightHand`、`LeftHand`（掛道具用） |
| 動作 | 全部做成同一個 `.glb` 裡的具名 animation clip，名稱照 §2，**30 fps**，原地動作（不要位移，位移由程式控制） |
| 描邊 | 不要在模型上做外擴描邊殼，程式會處理 |
| 檔案大小 | 主角與守關者 ≤ 3 MB，小怪 ≤ 800 KB（可用 Draco／meshopt 以外的方式壓，**不要用 Draco**，目前載入器沒掛解碼器） |
| 命名 | `source/models/{id}.glb`，id 照 §3，全小寫 |
| 細薄部件 | 圍巾、馬尾、翅膀、領帶要有厚度；圍巾與馬尾請加 2–3 節骨頭並做進動作裡（不做物理模擬） |

## 2. 動作清單

clip 名稱請**完全照這裡拼**，程式用名字找。標「循環」的首尾要接得起來。

### 2.1 主角三型態（student／brave／worker）

| clip 名稱 | 內容 | 長度 | 循環 |
|-----------|------|------|------|
| `idle` | 站立待機。大學生有點駝、勇氣超人挺胸圍巾飄、上班族肩膀垮 | 1.5–2 秒 | ✅ |
| `run` | 跑步 | 0.6–0.8 秒 | ✅ |
| `attack1`、`attack2`、`attack3` | 三段連續拳：左直拳、右勾拳、重拳。每段出拳點在 40% 處 | 各 0.35 秒 | |
| `dodge` | 向前翻滾或側滑 | 0.3 秒 | |
| `stun` | 被嚇到、定身（抱頭或僵直發抖） | 1 秒 | ✅ |
| `hurt` | 受擊後仰 | 0.3 秒 | |
| `die` | 倒下 | 0.9 秒 | |
| `transform` | 變身蓄力：握拳、圍巾與頭髮往上飄（只有 student、worker 需要） | 1 秒 | ✅ |
| `skill1` | 勇氣衝拳：壓低身體向前衝刺出拳（只有 brave） | 0.35 秒 | |
| `skill2` | 氣功彈：雙手合在腰側再往前推（只有 brave） | 0.4 秒 | |
| `skill3` | 氣功震地：跳起後單拳捶地（只有 brave），捶地點在 45% 處 | 0.6 秒 | |
| `ult` | 超勇氣波：雙手前推持續放光束，身體微微後仰抖動（只有 brave） | 2.3 秒 | |
| `victory` | 過關姿勢（選做） | 1.5 秒 | |

### 2.2 小怪

| clip 名稱 | 內容 | 長度 | 循環 |
|-----------|------|------|------|
| `idle` | 待機，要有「在嗆人」的感覺（叉腰、指指點點、扭屁股） | 1–1.5 秒 | ✅ |
| `run` | 移動 | 0.5–0.8 秒 | ✅ |
| `attack` | 攻擊，出手點在 60% 處。遠程怪（佛賴弟、假忙森）是丟東西 | 0.6 秒 | |
| `stun` | 暈眩 | 1 秒 | ✅ |
| `die` | 被打飛後倒地 | 0.9 秒 | |
| `scared` | 主角變身後發抖求饒（選做，很加分） | 1 秒 | ✅ |

### 2.3 守關者

小怪那五個，再加招式動作。沒做到的招式程式會退回用 `attack`。

| 角色 | 額外 clip |
|------|-----------|
| 錢大姐 | `skill1`（紙扇橫掃）、`skill2`（衝刺） |
| 藍教頭／藍經理 | `skill1`（吹哨）、`skill2`（指人大罵）、`skill3`（跺腳震地）；藍經理另加 `heal`（開會：坐下翻文件） |
| 惡夢／地獄／夢魘超人 | 和勇氣超人同一套（`skill1`–`skill3`），可直接共用勇氣超人的骨架與動作再調姿勢；另加 `talk`（雙手攤開說教）。夢魘超人加 `guard`（單手擋） |
| 幹譙龍完全體 | `skill1`（噴吐，持續 1.5 秒）、`skill2`（捶地） |
| 冠老闆 | `fly`（空中盤旋，循環）、`skill1`（俯衝）、`skill2`（撒大餅） |
| 新雞 | `skill1`（拿手機截圖後模仿出招） |
| 八卦蛇 | `skill1`（吐信噴出訊息泡泡） |
| 小天使 | 只要 `idle`（飄浮）、`talk`（嫌棄地指人）、`laugh`、`sign`（舉牌）；不戰鬥 |

## 4. 場景物件（P3，可晚做或不外包）

目前場景是程式用方塊搭的。外包的話每張地圖只需要 5–8 個可重複擺放的小物件，各 ≤ 2,000 面、一張 512 貼圖、無骨架：
校園（置物櫃、課桌椅、籃球架、司令台、校門）、荒野（枯樹、路牌、木屋、井）、職場（辦公隔板、電腦桌、影印機、會議桌、金色棲木）。
地面與整體搭建由程式處理。

## 5. 特效不外包

拳風、氣功彈、光束、衝擊波由程式在 3D 場景內製作，只需要 [`ASSETS.md`](ASSETS.md) §10 的貼圖。

## 6. 交付與驗收

1. **先交一個角色試做**：建議 `brave`（勇氣超人）加 `idle`、`run`、`attack1` 三個動作。使用者確認造型與風格後再做其餘的。
2. 每個檔案放進 `source/models/`，並把路徑與 clip 對照填進 `assets/manifest.json` 的 `models`（格式如下）。**填了那個角色就會自動換掉積木人，不用改程式。**
   ```json
   "brave": { "url": "assets/source/models/brave.glb", "height": 1.75, "rotationY": 0,
              "clips": { "idle": "idle", "run": "run", "attack1": "attack1", "skill1": "skill1" } }
   ```
3. 驗收方式：放進去後開遊戲實際跑。檢查項目：方向與腳底位置正確、動作名稱對得上、循環動作不跳、上百隻小怪同場時手機不卡、俯視鏡頭下輪廓認得出是誰。
4. 另請附原始檔（`.blend`／`.fbx`／`.ma` 皆可）放 `_archive/02_xianxia_battle/models/`，不進遊戲資料夾。
5. 授權：買斷，著作財產權歸使用者，可商用、可修改；不得使用無授權的現成資產或他人 IP 的模型。
