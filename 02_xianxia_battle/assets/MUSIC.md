## 1. 交付規格

| 項目 | 規格 |
|------|------|
| BGM 格式 | **每首同時交 `.mp3` 與 `.ogg`**（專案慣例；MP3 循環點會有空隙，OGG 用來無縫循環） |
| BGM 編碼 | 44.1kHz 立體聲；MP3 128kbps（專案曾把 192k 降到 128k 以縮短載入）；OGG 品質約 q4 |
| BGM 響度 | 約 −16 LUFS，各首之間聽起來一樣大聲；峰值不超過 −1 dBTP |
| 循環曲 | 開頭與結尾要能**無縫接回**，不要淡入淡出，尾端不要留殘響空白。請註明循環長度 |
| 音效格式 | `.mp3`，44.1kHz **單聲道**，96–128kbps；長度盡量短（多數 0.1–1 秒），開頭不要有靜音 |
| 音效響度 | 峰值約 −3 dB，同類音效音量一致 |
| 檔案大小 | 這是手機網頁遊戲：單首 BGM 建議 1.5MB 以內，全部音效合計 1MB 以內 |
| 母帶 | 未壓縮的 WAV 母帶請放 repo 根目錄的 `_archive/`，不要放進遊戲資料夾 |
| 路徑 | BGM：`02_xianxia_battle/assets/source/music/`　音效：`02_xianxia_battle/assets/source/sfx/` |
| 檔名 | 照下面各表，**勿改** |

## 2. 接進遊戲的方式

遊戲啟動時讀 `02_xianxia_battle/assets/manifest.json` 的 `audio` 欄位。把檔案放好後，把對應的值從 `null` 改成路徑，例如：

```json
"audio": {
  "bgm_battle": "assets/source/music/bgm_stage_1_1.mp3"
}
```

- **14 關都已經做出來了，每一關的鍵現在都會播**（v1.2 更新）。程式的規則是：
  - 進入某一關時，播 `bgm_stage_X_Y`；這個鍵還是 `null` 的話，退回播 `bgm_battle`。
  - 守關者登場後切到 `bgm_boss`。例外：1-4、2-2、4-1 這三關是黑影戰、沒有小怪波次，如果該關自己的曲子已經填了，就整關播它，不切 `bgm_boss`。
  - 過關播 `bgm_victory`；第一次變身的完整演出播 `bgm_transform`（還是 `null` 就靜音）。
  - 所以**每交一首關卡曲，把路徑填進對應的 `bgm_stage_X_Y`，那一關馬上就會換歌**，不需要改程式。
- 還沒接上的鍵：`bgm_title`、`bgm_talk`、`bgm_defeat`、`bgm_ending`、`bgm_credits`。先做關卡曲。
- **變身曲 `bgm_brave`（v1.3 新增，P0）**：程式已接上，變身期間會播這個鍵。目前暫時指向 `theme_braveguy_demo`（只有 9 秒、不是為循環做的），正式曲交付後把路徑換掉即可。原本選做的 `bgm_brave_layer` 取消。
- 已交付並接上的：`bgm_battle`／`bgm_stage_1_1`（都指向 `bgm_campus`）、`bgm_boss`、`bgm_victory`；`bgm_stage_2_1`／`2_2`（指向 `bgm_wild`）；`bgm_stage_3_0`（指向 `bgm_office_mute`）；`bgm_stage_3_1`–`3_5`（都指向 `bgm_office`）。**同一張地圖目前共用一首，「每關不同」還缺：1-0、1-2、1-3、1-4、2-2、3-2–3-5、4-1。**
- 音效目前全是程式合成（`js/audio.js`），**還沒有讀檔的功能**。音效檔交付後由 Claude 改程式接入，音樂這邊不用動程式。
- 瀏覽器規定要玩家點過畫面才能出聲，遊戲已用「開始」按鈕處理。

## 3. BGM 清單

### 3.1 每一關的戰鬥電音（使用者指定：每關不同）

共 14 關，每關一首，全部可無縫循環，長度 60–100 秒。每首都要有明確的 build-up 與 drop，並把**主角主題**（見 3.3）用該關的音色藏進去至少一次。

### 3.3 主題動機的要求

- **主角主題**：一段 4–8 小節、好記、哼得出來的旋律。每一關的戰鬥曲用該關的音色至少出現一次，`bgm_title` 與 `bgm_credits` 是它的完整版。
- **黑影主題**：主角主題的鏡像（小調、倒影或逆行皆可）。三首黑影曲（1-4、2-2、4-1）是同一個動機的三種情緒：可憐 → 暴怒 → 平靜。
- 終章兩個主題合一，是整個配樂的收尾。
- 小天使不用專屬主題曲，但可以有一個 2–3 個音的小動機（鈴鐺或鐘琴），在她講話或救起主角時出現。

### 3.4 數量與載入

- 戰鬥曲 14 首＋守關曲 1 首＋非戰鬥 7 首，共 22 首（另有 1 段選做的 stem）。
- 每關進場時才載入該關的曲子，所以總量大沒關係，但**單首仍請控制在 1.5MB 以內**。
- **14 關都已可玩**。目前只有 1-1 有自己的曲子，其餘 13 關都退回播同一首 `bgm_battle`，所以現在每關聽起來一樣。**下一批請依關卡順序交 `bgm_stage_1_0`、`1_2`、`1_3`、`1_4`**（地圖一），再往地圖二、三。
