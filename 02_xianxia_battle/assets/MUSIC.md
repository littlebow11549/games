## 0. 先知道這幾件事

| 項目 | 內容 |
|------|------|
| 遊戲 | 《勇氣超人 Brave Guy》：斜俯視 3D 動作，手機網頁遊戲。平凡大學生在夢裡闖進自己內心的黑暗世界，變身勇氣超人打倒心魔 |
| 調性 | **喜劇優先**。題材是霸凌、畢業的迷惘、職場的麻木，但每一場都要好笑。音樂可以熱血、可以賤、可以裝正經，不要沉重 |
| 風格方向 | 2000 年代日系動作遊戲與熱血動畫的感覺：明亮的旋律、強節奏、銅管與電吉他。校園偏放克與鼓號樂隊、荒野偏空曠與原聲樂器、職場是電梯音樂被打壞成戰鬥曲 |
| 目前狀態 | 遊戲已上線（佔位美術），**完全沒有音樂**；音效是程式即時合成的暫代音。BGM 接上就會響 |
| 原創性 | 全部要原創或確定可商用。不要模仿特定作品的旋律。變身曲只參考「魔法少女變身」這個類型的氣氛，不可沿用任何既有動畫的音樂 |

## 1. 交付規格

| 項目 | 規格 |
|------|------|
| BGM 格式 | **每首同時交 `.mp3` 與 `.ogg`**（專案慣例；MP3 循環點會有空隙，OGG 用來無縫循環） |
| BGM 編碼 | 44.1kHz 立體聲；MP3 128kbps（專案曾把 192k 降到 128k 以縮短載入）；OGG 品質約 q4 |
| BGM 響度 | 約 −16 LUFS，各首之間聽起來一樣大聲；峰值不超過 −1 dBTP |
| 循環曲 | 開頭與結尾要能**無縫接回**，不要淡入淡出，尾端不要留殘響空白。請註明循環長度 |
| 音效格式 | `.mp3`，44.1kHz **單聲道**，96–128kbps；長度盡量短（多數 0.1–1 秒），開頭不要有靜音 |
| 音效響度 | 峰值約 −3 dB，同類音效音量一致 |
| 檔案大小 | 這是手機網頁遊戲：單首 BGM 建議 1.5MB 以內，全部音效合計 1MB 以內 |
| 母帶 | 未壓縮的 WAV 母帶請放 repo 根目錄的 `_archive/`，不要放進遊戲資料夾 |
| 路徑 | BGM：`02_xianxia_battle/assets/source/music/`　音效：`02_xianxia_battle/assets/source/sfx/` |
| 檔名 | 照下面各表，**勿改** |

## 2. 接進遊戲的方式

遊戲啟動時讀 `02_xianxia_battle/assets/manifest.json` 的 `audio` 欄位。把檔案放好後，把對應的值從 `null` 改成路徑，例如：

```json
"audio": {
  "bgm_battle": "assets/source/music/bgm_campus.mp3"
}
```

- **現在程式會播的只有三個鍵**：`bgm_battle`（一般戰鬥）、`bgm_boss`（守關戰）、`bgm_victory`（過關）。先交這三首，填進去就能在正式網站聽到。
- 其餘的鍵已經預留在 manifest 裡，但程式還沒呼叫；對應的關卡與系統做出來時 Claude 會接上。
- 音效目前全是程式合成（`js/audio.js`），**還沒有讀檔的功能**。音效檔交付後由 Claude 改程式接入，音樂這邊不用動程式。
- 瀏覽器規定要玩家點過畫面才能出聲，遊戲已用「開始」按鈕處理。

### 主題動機的要求

- **主角主題**：一段 4–8 小節、好記、哼得出來的旋律。`bgm_campus`、`bgm_title`、`bgm_wild`、`bgm_office`、`bgm_credits` 都是它的不同編曲。
- **黑影主題**：主角主題的鏡像（小調、倒影或逆行皆可）。三首黑影曲是同一個動機的三種情緒：可憐 → 暴怒 → 平靜。
- 終章兩個主題合一，是整個配樂的收尾。
- 小天使不用專屬主題曲，但可以有一個 2–3 個音的小動機（鈴鐺或鐘琴），在她講話或救起主角時出現。

## 5. 配音（另案，列在這裡供統籌）

- 腳本每句台詞有四位數 ID，配音檔名用它：`02_xianxia_battle/assets/source/voice/vo_1042.mp3`。
- 規格：MP3 96–128kbps 單聲道，一句一檔，前後不留空白。
- 量：主線 670 句、戰鬥泡泡 52 句。可以只配主線，或只配「怪叫與語氣詞」（主角的出拳喊聲、小天使的「喔。」、俊熊的「蛤～～」、八卦蛇的「私私～」），其餘用文字。
- 語氣參考 `SCRIPT.md` 開頭的「角色語氣速查」。

## 6. 交付時請一併做的事

1. 在 `02_xianxia_battle/assets/source/` 放一份 `AUDIO_DELIVERY.json`（或 Markdown），列出每個檔案的長度、取樣率、位元率、響度、是否可循環與循環長度、製作工具、**授權來源**。
2. 在 `docs/handoffs/` 新增交接報告，並更新 `docs/HANDOFF.md`（專案規定，見根目錄 `AGENTS.md`）。
3. P0 三首 BGM 請直接把路徑填進 `assets/manifest.json`，並實際開遊戲聽一次確認會循環、音量合理。
4. 不要改 `js/` 裡的程式；音效接入由 Claude 處理。
5. 建議先交 P0（三首 BGM 加主角主題的 demo），使用者確認方向後再做其餘的。
