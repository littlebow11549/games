# 勇氣超人 Brave Guy — 劇情腳本（初稿 v0.1，2026-11-11）

依 [`DESIGN.md`](DESIGN.md) v0.5 的三大地圖結構撰寫。**整份都是 Claude 的初稿提案**，尚未經使用者確認；
水手服少女、藍衣大叔、六隻心魔的身分沿用企劃書的推想，使用者的原始設定若不同，對應場次要重寫。

## 讀法

- 每句台詞前的編號（例 `1003`）是台詞 ID：千位數是區域，之後配音檔可命名為 `vo_1003.mp3`。
- 〔 〕是演出與玩法指示，不會顯示給玩家。
- 「泡泡」指戰鬥中在角色頭上冒出的短句，不暫停遊戲。
- 手機上一句最多兩行，所以台詞刻意寫短。
- 主角名字未定，暫稱「主角」；小天使與惡夢超人會用各種方式叫他，就是不叫名字。

## 角色語氣速查

| 角色 | 語氣 | 口頭習慣 |
|------|------|----------|
| 主角 | 嘴硬、自嘲、容易心虛 | 「那是策略性……」 |
| 小天使 | 毒舌、嫌棄、絕不直接稱讚 | 最高評價是「還行」 |
| 惡夢超人 | 平靜、冷、講得有道理 | 從不大聲，句尾常是「對吧」 |
| 心魔 | 打之前囂張，打之後卑微 | 被打敗後開始講理由 |
| 藍衣大叔 | 永遠在吼，越吼越離題 | 「我當年……」 |
| 水手服少女 | 爽朗、直接、其實沒想那麼多 | 用紙扇敲人 |
